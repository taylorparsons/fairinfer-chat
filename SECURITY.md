# Security policy

## Supported release

Security fixes are maintained on the latest release and the default branch.

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/taylorparsons/fairinfer-chat/security/advisories/new). You can also reach the maintainer through the [FairInfer contact page](https://fairinfer.com/work/). Include the release or commit, affected component, impact and reproduction steps on a site or data you are authorized to use. Please redact credentials and personal information.

The project covers the widget, Selenium content companion, release packaging, and their integration. Report issues specific to Gemma, Chrome, ChromeDriver, or the upstream Selenium MCP through their maintainers' security channels.

## Deployment

Follow the [install guide](INSTALL.md) and review any sources before publishing the knowledge file. See the [security review](SECURITY-REVIEW.md) for the current boundaries and verification.
